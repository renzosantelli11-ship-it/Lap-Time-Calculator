## ✨ Features & Scope

### ✅ What You Can Do
* **Log Lap Times:** Enter individual lap times in a standard `MM:SS.SSS` or decimal format.
* **Real-Time Telemetry:** Automatically calculates and displays:
  * ⚡ **Fastest Lap** (Best Sector / Personal Record)
  * 🐢 **Slowest Lap**
  * 📊 **Average Pace** across the current stint
* **Session Reset:** Clear all logged laps and reset session metrics with a single click.
* **Dark Mode Telemetry UI:** Motorsport-inspired interface built for low-light legibility.

### ❌ Current Limitations (Out of Scope)
* **No Database / Cloud Storage:** Lap data is stored strictly in memory for the current browser session. Refreshing the page resets your data.
* **No Telemetry File Imports:** Manual entry only (does not import `.csv` or direct game telemetry logs yet).
* **Single Driver Session:** Designed for one active session at a time (no multi-driver comparisons).
